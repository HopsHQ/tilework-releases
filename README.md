# Tilework downloads

Signed, notarized builds of **Tilework** for Mac, which arranges your iPhone Home Screen
from your Mac. The source is private; this repository only holds releases.

Download the latest `Tilework-<version>.zip` from [Releases](../../releases/latest), unzip it,
and move Tilework to Applications. Installed copies check this repository for updates
(Settings › Updates) and only install releases signed with Tilework's release key.

`tilework-update.json` is the signed update feed: an Ed25519-signed list of each download's
version, address, size and SHA-512.
